# Example settings files

Copy any of these next to `GymClock.exe` and rename it to `gymclock.settings.txt`.
A file with that name sitting beside the executable takes priority over
`%AppData%\GymClock\settings.txt`, which makes it easy to keep a USB-stick copy or
several shortcuts configured differently.

`station-builder.txt` shows the richer station format - per-station work/rest
instructions, the on-screen table, and the station-wording toggle - built with the
**Stations** tab of the settings dialog (press `S`). See the main
[README](../README.md#stations--session-builder) for the full explanation.
